# getcourse-neuromail

Скилл для создания email-рассылок в GetCourse с помощью нейросетей.

## Что внутри

- Правила вёрстки писем: табличная вёрстка, инлайн-стили, запрет скриптов/видео/анимаций, проверка CSS-свойств и значений через [JSON API Can I email](https://www.caniemail.com/api/data.json) с учётом клиентов, версий и примечаний
- Полный справочник переменных GetCourse (пользователи, заказы, покупки) с пометками о доступности в процессах
- Подключение скрипта импорта готового HTML в редактор рассылки
- Загрузка файлов в хранилище GetCourse через MCP; без MCP — письмо с плейсхолдерами и ручная загрузка картинок

## Подключение MCP

**Для загрузки файлов сразу в файловое хранилище GetCourse необходимо подключить MCP-сервер GetCourse с доступным инструментом загрузки файлов (`upload_file`).** Перед загрузкой проверь наличие этого инструмента в текущей сессии и используй его согласно доступной схеме параметров. Ссылку на файл бери из ответа инструмента.

Если MCP не подключён или инструмент загрузки недоступен, предложи подключить MCP через настройки используемой среды. При этом можно сразу создать письмо с плейсхолдерами на месте картинок; затем пользователь отдельно загружает картинки вручную на платформе и заменяет плейсхолдеры полученными ссылками.

Для остальных операций с GetCourse используй доступные MCP-инструменты, которые их поддерживают.

## Использование

Файл `SKILL.md` — сам скилл. Положите его в папку, где ваша нейросеть ищет скиллы (например, `skills/`), или приложите к чату перед задачей на рассылку.

Материалы мастер-класса «Нейрорассылка в GetCourse»: план эфира — https://school.one-way.dev/neuromail_plan_efira
