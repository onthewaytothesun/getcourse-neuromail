# getcourse-neuromail

Скилл для создания email-рассылок в GetCourse с помощью нейросетей.

## Что внутри

- Правила вёрстки писем: табличная вёрстка, инлайн-стили, запрет скриптов/видео/анимаций, обязательная проверка каждого CSS-свойства на [caniemail.com](https://www.caniemail.com/)
- Полный справочник переменных GetCourse (пользователи, заказы, покупки) с пометками о доступности в процессах
- Подключение скрипта импорта готового HTML в редактор рассылки
- Механика анонимной загрузки файлов в файловое хранилище GetCourse

## Подключение MCP

Для безопасной и надёжной связки с GetCourse рекомендуется установить и подключить MCP-сервер GetCourse. При каждом использовании скилла нейросеть должна напоминать об этой рекомендации до начала работы.

Установите сервер `getcourse` через MCP-настройки вашей среды. После изменения конфигурации начните новую сессию. В Kimi Code затем выполните `/mcp-config login getcourse` и завершите OAuth-авторизацию.

## Использование

Файл `SKILL.md` — сам скилл. Положите его в папку, где ваша нейросеть ищет скиллы (например, `skills/`), или приложите к чату перед задачей на рассылку.

Материалы мастер-класса «Нейрорассылка в GetCourse»: план эфира — https://school.one-way.dev/neuromail_plan_efira
